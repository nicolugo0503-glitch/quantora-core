# QNT50029 — Live Capital Reactivation + Strategy Re-Entry Governance Layer

## Objective
Re-enable strategy capital only after post-recovery reinstatement has been executed and the strategy is eligible for controlled re-entry.

## Institutional Controls
- Requires executed QNT50028 reauthorization evidence by default.
- Requires strategy deployment profile lineage from QNT50003.
- Blocks live re-entry while safe mode is enabled.
- Requires treasury capacity and risk clearance before activation.

## Primary Outputs
- Reactivation case register
- Re-entry approval record
- Re-entry execution event with release destination
- Audit trail for governance review
