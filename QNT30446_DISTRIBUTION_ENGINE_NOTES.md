# QNT30446 — Distribution Engine

## Mission objective
Install the growth and scale layer: leads, referrals, campaigns, and onboarding flows.

## Added backend capabilities
- leads table + creation endpoint
- campaigns table + creation endpoint
- referrals table + creation endpoint
- onboarding flows table + creation endpoint
- distribution summary package and health score

## Added frontend capability
- distribution engine panel

## Key endpoints
- `GET /workspace/distribution/summary`
- `POST /workspace/distribution/leads/create`
- `POST /workspace/distribution/campaigns/create`
- `POST /workspace/distribution/referrals/create`
- `POST /workspace/distribution/onboarding/create`

## Strategic value
This mission installs the distribution machinery required to scale acquisition, create growth loops, and turn Quantora into a compounding operating company.
