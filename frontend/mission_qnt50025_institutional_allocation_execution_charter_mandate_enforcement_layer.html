QNT50025 — Institutional Allocation Execution Charter + Mandate Enforcement Layer

Institutional governance layer that converts executive arbitration into execution charters, scoped mandates, and enforceable directives before capital can move downstream.

Capabilities

  • Synchronizes executive arbitration, committee, risk, treasury, control-loop, and intercompany posture.
  • Registers execution charters that define governed execution scope, allowed actions, and hard notional limits.
  • Creates institutional mandates linked to charters for strategy-specific capital deployment authority.
  • Issues or blocks downstream directives using arbitration status, liquidity support, risk posture, and mandate alignment.

Primary endpoints

  • GET /institutional-charter/health
  • GET /institutional-charter/summary
  • POST /institutional-charter/register-charter
  • POST /institutional-charter/register-mandate
  • POST /institutional-charter/enforce-mandate
  • POST /institutional-charter/reset
