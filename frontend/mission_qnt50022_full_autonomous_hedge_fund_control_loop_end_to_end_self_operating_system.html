QNT50022 — Full Autonomous Hedge Fund Control Loop (End-to-End Self-Operating System)

Mission control layer that synchronizes deployment, risk, performance, treasury, and autonomous execution into one auditable operating loop.

Capabilities

  • Builds a unified control snapshot from QNT50003, QNT50004, QNT50005, QNT50006, QNT50008, and QNT50018.
  • Applies gating rules before autonomous execution is allowed.
  • Creates end-to-end control plans and executes live/paper autonomous cycles through the existing execution path.
  • Persists plans, cycles, escalations, and audit events for governance-grade supervision.

Primary endpoints

  • GET /autonomous-control/health
  • GET /autonomous-control/summary
  • POST /autonomous-control/sync-context
  • POST /autonomous-control/plan-loop
  • POST /autonomous-control/execute-loop
  • POST /autonomous-control/reset
