QNT30678 — Live Allocation Exception Governance Layer

Institutional exception command layer supervising unresolved live-allocation breaks after post-close oversight.

Core functions

  • Aggregate exception pressure across oversight, continuity, settlement, reconciliation, governance, committee, and compliance layers.
  • Score exception-governance readiness using real artifact stores.
  • Emit governed actions: RESOLVE, REVIEW, HOLD, ESCALATE.
  • Persist run history and policy controls for auditability.

Endpoints

  • GET /api/live-allocation-exception-governance-layer/summary
  • POST /api/live-allocation-exception-governance-layer/run
  • GET /api/live-allocation-exception-governance-layer/audit
  • POST /api/live-allocation-exception-governance-layer/policy
