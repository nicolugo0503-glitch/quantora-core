QNT50013 — Official Books Release + Distribution Archive Certification Layer

Quantora now converts a closed distribution period into an officially released books package, certifies archive evidence, and seals retention metadata for downstream governance, audit, and regulator retrieval.

Official books release Archive certification Retention governance Distribution evidence lock

Control Flow

  • register-release binds a closed QNT50012 period into an official books release package.
  • certify-archive certifies the archive payload and checksum manifest before final release.
  • release seals the official books package with release authority and retention metadata.

Institutional Checks

  • Closed period evidence is required before registration.
  • Open settlement breaks can block release registration.
  • Archive certification can be required before official release is permitted.

Endpoints

  • GET /official-books/health
  • POST /official-books/register-release
  • POST /official-books/certify-archive
  • POST /official-books/release
