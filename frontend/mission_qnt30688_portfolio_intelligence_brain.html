QNT30688 — Portfolio Intelligence Brain

Institutional intelligence layer for orchestrating portfolio posture after strategy selection, regime detection, and deployment analysis.

Core functions

  • Score portfolio posture using strategy selection, regime detection, deployment quality, reallocation quality, rotation, defense, governance, compliance, and execution breadth.
  • Determine whether the portfolio should orchestrate, scale, deploy, defend, review, hold, or escalate.
  • Persist run history and policy controls for auditability.

Endpoints

  • GET /api/portfolio-intelligence-brain/summary
  • POST /api/portfolio-intelligence-brain/run
  • GET /api/portfolio-intelligence-brain/audit
  • POST /api/portfolio-intelligence-brain/policy
