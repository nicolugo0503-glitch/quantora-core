# QNT30736 — Institutional Cross-Venue Deployment Routing Layer

Purpose:
- govern capital routing across multiple execution venues after multi-channel deployment orchestration approval
- score routing posture across venue capacity, execution quality, settlement quality, failover coverage, and venue concentration
- cross-check operator, release, safety, recovery, fund admin, liquidity, mandate, and orchestration posture before allowing routing

Key outputs:
- routing score
- routing band
- operator review requirement
- routing book entries and alerts
