# QNT30663 — Capital Committee Oversight Mesh

Institutional committee layer governing release authority after execution governance.

## Added
- capital committee casebook derived from execution governance, compliance, treasury, and strategic inputs
- oversight lanes for committee review windows
- authority matrix for release, review, and hold decisions
- committee queue with approve, review, and escalate actions
- audit-ready run log and policy thresholds

## API
- GET `/api/capital-committee-oversight-mesh/summary`
- POST `/api/capital-committee-oversight-mesh/run`
- GET `/api/capital-committee-oversight-mesh/audit`
- POST `/api/capital-committee-oversight-mesh/policy`
