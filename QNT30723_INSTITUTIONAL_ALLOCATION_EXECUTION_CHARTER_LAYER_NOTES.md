# QNT30723 — Institutional Allocation Execution Charter Layer

This mission converts approved executive allocation policy into a governed execution charter.

## What it governs
- staged execution waves
- liquidity buffers
- reserve holds
- crossing cost discipline
- cross-system posture gating before execution authority is granted

## Cross-system posture checks
- operator command posture
- institutional release control
- live broker safety layer
- fund admin reconciliation posture
- forensic and recovery posture
- liquidity, regime, rotation, and defense posture
- executive command, committee, arbitration, and allocation policy posture

## Outcome states
- APPROVED / CHARTER_EXECUTE
- OPERATOR_REVIEW / STAGED_EXECUTION
- WATCH / HOLD_CHARTER
- BLOCKED / DO_NOT_EXECUTE
