# QNT30680 Integration Notes

Mission: QNT30680 Live Allocation Recovery Authority

This layer consumes remediation, exception governance, continuity, oversight, settlement,
reconciliation, governance, compliance, pnl, and execution artifacts to determine whether
impaired live capital should recover, rotate, reduce, exit, or escalate.

Primary outputs:
- recovery overview
- recovery book
- recovery decisions
- recovery agenda
- audit history

Institutional actions:
- RECOVER
- ROTATE
- REDUCE
- EXIT
- ESCALATE
