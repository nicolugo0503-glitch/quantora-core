# QNT30458 — Institutional Data Room + Allocator Access Layer

## Mission objective
Install the allocator-facing data room and access control layer.

## Added backend capabilities
- data room folder registry
- document registry
- allocator access registry
- allocator session registry
- data room summary package and health score

## Added frontend capability
- institutional data room and allocator access panel

## Key endpoints
- `GET /workspace/data-room/summary`
- `POST /workspace/data-room/folders/create`
- `POST /workspace/data-room/documents/create`
- `POST /workspace/data-room/access/create`
- `POST /workspace/data-room/sessions/create`

## Strategic value
This mission gives Quantora an allocator-ready review surface for diligence, reporting access, and controlled institutional visibility.
