# QNT30690 Integration Notes

Mission: QNT30690 Cross-Fund Allocation

This layer consumes multi-fund orchestration, portfolio intelligence brain, strategy selection AI,
regime detection, governance, committee oversight, compliance, execution, pnl, capital-ledger,
and multi-fund architecture artifacts to determine how capital should be allocated across funds.

Primary outputs:
- cross-fund allocation overview
- cross-fund book
- cross-fund decisions
- cross-fund agenda
- audit history

Institutional actions:
- ALLOCATE
- REBALANCE
- REDISTRIBUTE
- HOLD
- ESCALATE
