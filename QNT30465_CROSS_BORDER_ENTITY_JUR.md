# QNT30465 — Cross-Border Entity, Jurisdiction, and Fund Structure Layer

## Mission objective
Install the legal-operating layer across entities, jurisdictions, fund structures, and linked compliance controls.

## Added backend capabilities
- entity registry
- jurisdiction registry
- fund structure registry
- compliance control link registry
- structure summary package and health score

## Added frontend capability
- cross-border entity and fund structure panel

## Key endpoints
- `GET /workspace/fund-structure/summary`
- `POST /workspace/fund-structure/entities/create`
- `POST /workspace/fund-structure/jurisdictions/create`
- `POST /workspace/fund-structure/structures/create`
- `POST /workspace/fund-structure/controls/create`

## Strategic value
This mission gives Quantora the structure layer needed for multi-entity, multi-jurisdiction, institutional-scale operations.
