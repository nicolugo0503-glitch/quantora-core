# QNT50013 — Official Books Release + Distribution Archive Certification Layer

This mission extends the QNT50012 distribution close into an institutional release plane.

## Added
- Official books release registration bound to closed periods from QNT50012
- Archive certification before final release authority
- Retention metadata and release evidence logging
- Health, summary, release inventory, certification, and reset endpoints

## Governance intent
No period can graduate into an official books package unless period-close evidence exists, notice posture is complete, and archive certification is attached when policy requires it.
