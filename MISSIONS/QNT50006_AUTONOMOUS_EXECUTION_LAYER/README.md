# QNT50006 — Autonomous Execution Layer

This mission closes the institutional execution loop.

## Scope
- Ingest approved QNT50003 release tickets
- Apply QNT50004 kill-switch and QNT50005 performance gating
- Build autonomous execution envelopes with decision lineage
- Route eligible orders through QNT50001
- Escalate exit-side tickets that require position inventory context

## Institutional posture
Autonomy is disabled by default and remains constrained by policy, safe mode, broker availability, and risk thresholds.
