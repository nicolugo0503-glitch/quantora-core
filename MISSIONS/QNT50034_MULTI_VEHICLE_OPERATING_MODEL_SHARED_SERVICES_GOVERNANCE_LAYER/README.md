# QNT50034 — Multi-Vehicle Operating Model + Shared Services Governance Layer

This mission adds governed shared-services operating model controls for running multiple Quantora vehicles under common operating functions.

## What it adds
- Governed shared-services model registration for multi-vehicle operations.
- Budget, live-mode, and directive-alignment enforcement.
- Approval, execution, and closure workflow with audit logging.
- Dependency on executed QNT50033 vehicle launch evidence before activation.

## Primary dependencies
- QNT50033 executed vehicle launch evidence
- QNT50004 risk posture
- QNT50008 treasury posture
