- `backend/`
- `frontend/`
- `MISSIONS/`
- `config/`
- `launchers/`
- `state/`
- `artifacts/`

Historical snapshots are archival only:
- `QUANTORA_FULL_PROJECT_QNT30427_PORTFOLIO_RISK_GOVERNANCE/`
