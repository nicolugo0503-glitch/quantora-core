# QNT30678 Integration Notes

Mission: QNT30678 Live Allocation Exception Governance Layer

This layer consumes live-allocation post-close oversight, close, reconciliation, settlement,
continuity, governance, committee oversight, and compliance artifacts to identify unresolved
institutional exceptions after post-close supervision.

Primary outputs:
- exception governance overview
- exception book
- exception decisions
- exception agenda
- audit history

Institutional actions:
- RESOLVE
- REVIEW
- HOLD
- ESCALATE
