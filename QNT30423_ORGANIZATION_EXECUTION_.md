# QNT30423 — Organization-Level Execution & Capital Engine

This mission establishes per-organization fund operations inside the strict multi-tenant Quantora workspace layer.

- org-scoped capital accounts
- org-scoped strategy registry
- org-scoped capital allocations
- org-scoped execution order ledger
- org performance summary endpoints
- org execution/capital panel

Institutional decision:
- broker configuration is scoped per organization, not shared globally
